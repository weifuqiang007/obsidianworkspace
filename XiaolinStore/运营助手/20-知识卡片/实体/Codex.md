# Codex

## 在本系统中的角色

Codex 是 Agent 执行层：读取项目目录和 Markdown，检索已有 Wiki，创建或更新页面，维护双链、索引和日志，并按 `AGENTS.md` 的规则工作。

## 适合承担

- 新资料理解和项目路由
- 查重与增量更新
- 来源摘要、概念、实体和主题提炼
- 链接、索引和日志维护
- 失效链接、缺失字段和长期未更新内容巡检

## 不应替代

高价值资料选择、敏感结论判断、来源冲突裁决和不可逆修改仍应由人确认。
