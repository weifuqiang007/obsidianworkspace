# 知识库权限框架讲解入口

> [!abstract] 一句话结论
> `KbPrincipal` 虽然类体为空，但它继承了 `Principal` 的全部字段。请求时真正创建哪种 Principal，不由控制器的类型标注决定，而由 `ScopeRegistry` 当前注册的 Policy 决定。

## 必须区分的三个时间点

| 时间点 | 发生什么 | 是否每次请求都执行 |
|---|---|---|
| Python 导入阶段 | 定义类、执行模块顶层注册语句 | 否，每个进程通常只导入一次 |
| FastAPI 应用构建/启动 | `create_app()` 注册中间件、扫描 hooks、注册路由；之后进入 `lifespan()` | 否，每个 worker 一次 |
| HTTP 请求阶段 | 认证、角色检查、构造 Principal、过滤数据 | 是 |

> [!warning] 不要混淆
> `PreAuthDependency` / `ViewerDependency` 是 FastAPI 路由依赖，不是 ASGI 中间件。全局中间件只是在请求外层处理上下文清理、CORS、GZip、Trace、传输加密等。
