# 本地语音陪伴 Agent 最小闭环

## 一句话定义

本地语音陪伴 Agent 最小闭环，是指在本机完成“听见用户、识别内容、生成回复、用语音说出回复”的最小可验证系统。

## 核心问题

做虚拟人情感陪伴项目时，第一阶段应该先验证什么？

## 核心要点

- 最小闭环不是完整产品，而是验证语音交互链路是否成立。
- 基础链路为：VAD → Whisper → 本地 LLM → TTS → 播放。
- 第一阶段不要过早投入复杂人设、长期记忆、网页面板和角色热切换。
- 每一层都应该能单独验证，避免所有模块一起启动后无法定位问题。
- 语音链路跑通后，再逐步增强情绪识别、记忆、虚拟形象和陪伴策略。

## 适用场景

- 虚拟人情感陪伴项目的早期原型。
- 本地隐私型 AI 伴侣或桌面陪伴工具。
- 需要验证语音输入、语音回复和低延迟体验的项目。

## 局限或易错点

- 跑通语音链路不等于具备真实陪伴感。
- 本地部署依赖硬件条件，显存不足会影响模型选择和响应速度。
- 语音合成的音色克隆涉及授权和伦理边界。
- 没有长期记忆、人格一致性和安全策略时，产品仍然只是语音聊天 demo。
