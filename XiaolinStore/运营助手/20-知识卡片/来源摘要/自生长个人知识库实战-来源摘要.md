# 自生长个人知识库实战：来源摘要

## 一句话摘要

文章提出用 Raw、Wiki、Schema 三层结构和 Agent 增量维护机制，把 Obsidian 从资料仓库变成会持续积累理解、关系和来源的个人知识系统。

## 核心观点

1. 传统检索问答会反复从碎片拼答案，但不会维护知识本身。
2. 新资料进入后，知识库必须留下新增、补充、链接、冲突或待解决问题等变化。
3. Raw 保存证据，Wiki 保存理解，Schema 约束维护行为。
4. Obsidian 负责本地存储、连接和呈现；[[Codex]] 等 Agent 负责执行与编排。
5. 人仍需决定哪些资料值得保留，并审核关键结论。

## 可执行启发

- 项目之间先做路由映射，避免同一项目重复建库。
- 每个项目有自己的 Schema、索引、日志与主题地图。
- 来源摘要、概念、实体和主题拆成独立页面。
- 先用一篇文章跑通闭环，再扩展到历史对话、会议和代码研究记录。
