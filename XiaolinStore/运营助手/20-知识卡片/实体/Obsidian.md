# Obsidian

## 在本系统中的角色

Obsidian 同时承担本地 Markdown 存储、人机操作界面和知识关系观察窗口。其双链、反向链接、图谱和插件生态适合 Agent 对文件进行可定位、可追踪的增量维护。

## 优势

- 数据保存在普通文件夹中，工具可替换。
- Markdown 适合版本控制和 Agent 读写。
- 双链和图谱能观察核心节点、孤立页面与跨主题关系。

## 边界

Obsidian 负责保存和呈现，本身不会自动保证知识质量；归档、引用和冲突规则仍由 Schema 与人工审核决定。
