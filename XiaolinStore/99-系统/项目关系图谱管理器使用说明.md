# 项目关系图谱管理器使用说明

> [!summary] 一句话说明
> 这是一个随知识库一起通过 GitHub 同步的 Obsidian 插件。它会自动给每个顶层项目文件夹维护一张独立关系图谱，在 Windows 和 macOS 上使用方法完全相同。

## 日常使用

默认已经开启自动同步，一般不需要做任何事：

- 启动 Obsidian 时，自动检查一次项目图谱。
- 新建顶层项目文件夹时，自动增加对应图谱。
- 删除顶层项目文件夹时，自动移除对应图谱书签。
- 重命名顶层项目文件夹时，自动更新图谱书签。
- 项目内部新增、修改、移动或删除笔记时，Obsidian 图谱自身会实时更新，不需要插件重新生成。

图谱入口位于左侧 **书签 → 项目关系图谱**。

## 手动刷新

如果 Git 拉取完成后没有立即看到变化，可以使用下面任意一种方式：

1. 点击 Obsidian 最左侧功能栏中的 **刷新项目关系图谱** 按钮（循环箭头图标）。
2. Windows 按 `Ctrl+P`，macOS 按 `Cmd+P`，搜索并执行 **项目关系图谱管理器：刷新项目关系图谱**。
3. 打开 **设置 → 第三方插件 → 项目关系图谱管理器**，点击 **刷新项目图谱**。

## 新建项目

在知识库最外层新建一个普通文件夹，例如 `新项目`。插件会自动创建 `新项目 · 项目图谱`。

只有最外层文件夹会被当作项目，项目内部的子文件夹不会单独生成图谱。

## 删除项目

删除或移走顶层项目文件夹后，插件只会删除对应的图谱书签，不会额外删除任何笔记或附件。

## 哪些目录不会被当作项目

默认忽略：

- 名称以 `.` 开头的隐藏目录
- `99-系统`
- `Excalidraw`
- `OtherFilesOrPics`
- `webclip`

如需修改，打开 **设置 → 第三方插件 → 项目关系图谱管理器 → 忽略的顶层文件夹**。

## 在新电脑上启用

1. 从 GitHub 克隆或拉取整个知识库。
2. 用 Obsidian 打开知识库目录。
3. 如果 Obsidian 弹出第三方插件安全提示，确认信任自己同步下来的仓库。
4. 打开 **设置 → 第三方插件**，确认 **项目关系图谱管理器** 已开启。
5. 插件启动后会自动生成项目图谱；也可以点击左侧循环箭头按钮手动刷新。

插件文件、启用清单、设置、图谱书签和本说明都会通过知识库的 Git 同步脚本同步。窗口布局文件不会同步，因此不会把某台电脑的窗口排列强加到另一台电脑。

## Git 多设备使用建议

1. 开始使用某台电脑前先执行 `git pull`。
2. 结束后执行知识库同步脚本并推送。
3. 尽量不要在两台电脑离线时同时新增或重命名顶层项目文件夹。
4. 若 `.obsidian/bookmarks.json` 发生冲突，先保留任意一侧文件，再运行插件的手动刷新命令即可重新生成“项目关系图谱”组；其他普通书签会保留。

## 分享给其他人

可直接发送 `99-系统/插件发布/project-graph-manager-1.0.0.zip`。安装包只包含插件程序、默认设置和说明，不包含本仓库的笔记或书签数据。

对方解压后，把整个 `project-graph-manager` 文件夹放入其仓库的 `.obsidian/plugins/`，然后在 **设置 → 第三方插件** 中启用即可。安装包内的 `README.md` 包含 Windows 和 macOS 的完整步骤。
