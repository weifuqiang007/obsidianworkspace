# 反身性研究核心代码维护规则

- 本目录统一对应 Codex 项目 `zhangyichi`、`ruoyi-fastapi-backend` 和 `ruoyi-fastapi-frontend`。
- 遵循 Vault 根目录 `AGENTS.md`，不复制同一问题到三个独立知识库。
- 项目范围：反身性研究产品、前端交互、后端服务、RAG/知识库、权限体系、研究生成区和反思区。
- 代码事实必须链接仓库路径、提交或明确版本；架构推断标记为“推断”。
- 前端、后端、产品规则和数据模型分开建卡，通过主题地图连接。
- 调试记录应包含问题、复现条件、调用链、根因、修复和验证。
- 不在知识库中保存密钥、生产日志中的隐私数据或未脱敏用户内容。
